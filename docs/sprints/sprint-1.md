# Sprint 1

## Objetivo
Entregar o núcleo funcional do Gestor Diário, integrando progressivamente aplicação mobile, mini API e persistência.

## Status
Em desenvolvimento.

## Escopo
Observado no código atual, sem certificação de aceite: telas de criação, edição e detalhes de tarefas e projetos, calendário, configurações, navegação e persistência local de tarefas e projetos via AsyncStorage. A tela de login não possui autenticação real.

Nesta etapa executar somente organização, documentação, Git e GitHub. A integração da mini API e a persistência remota são posteriores.

## Definition of Done
- [ ] Funcionalidade implementada
- [ ] Critérios de aceite atendidos
- [ ] Testes executados e aprovados
- [ ] Código versionado
- [ ] PR realizado
- [ ] Documentação atualizada
- [ ] Build funcional

As falhas atuais estão registradas na [auditoria](../auditoria-inicial.md). Os requisitos e critérios de aceite oficiais aguardam o PDF.
